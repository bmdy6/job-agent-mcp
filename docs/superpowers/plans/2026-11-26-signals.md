# Recruiting signals implementation plan

> **For agentic workers:** Execute inline using executing-plans; the existing feat/50-signals worktree isolates this work.

**Goal:** Persist recruiter/requirement signals, classify replies and expose invitation and greeting conversion evidence for #50.

**Architecture:** Platform projections produce unified JobListing fields; migration 6 owns all new persistent fields/tables. Service orchestrates bounded classification using the scoring provider; store owns persistence and cohort queries. Existing greeting_version is the only version function.

**Tech Stack:** Python, SQLite, Pydantic, unittest, Ego Lite.
